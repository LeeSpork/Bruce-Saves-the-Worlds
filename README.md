# Bruce Saves the Worlds
![Thumbnail](/thumbnail.png#1)

Can you help Bruce save his home planet? A story mod for Outer Wilds, made for the [6th Outer Wilds mod jam](https://outerwildsmods.com/jam/aug-2026/).

## Integrations with other mods
Includes achievements for the [Achievements+](https://outerwildsmods.com/mods/achievements/) mod.

## Languages
- English
- Chinese (translation by @SanBaiMing)
- Russian (translation by @HanSoloCh)
